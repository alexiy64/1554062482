Задания 7,8,9:

Задание 7. Язык С: ввод-вывод данных, условный оператор.
Можно использовать ИИ. При этом знать, что в программе каждый оператор делает.
Изучить среду программирования на языке С. 
Написать программу, которая на входе получает коэффициенты квадратного уравнения, а на выходе выдает решения. 
Сделать два варианта работы программы: 
а) данные вводятся и выводятся в окне, 
б) данные считываются из файла и выводятся в файл.

Задание 8. Язык С: массивы и циклы.
Можно использовать ИИ. При этом знать, что в программе каждый оператор делает.
Изучить, как описываются в С массивы. Изучить, какие бывают циклы. 
Написать программу, которая сортирует массив.
Написать программу, которая считывает массив чисел из файла, вычисляет и выдает в файл: среднее арифметическое, среднеквадратическое отклонение. Используя OMP распараллелить алгоритм вычисления на любое количество потоков. Продемонстрировать разницу во времени между 1, 2, 4 потоками.

Задание 9. Язык С: Функции
Можно использовать ИИ. При этом знать, что в программе каждый оператор делает.
Создать функцию, которая считает скалярное произведение двух векторов по их координатам.
Написать программу, которая создает случайным образом шесть векторов и находит все попарные скалярные произведения. 
Результат вывести в файл.
